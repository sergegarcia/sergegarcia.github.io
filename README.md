# Serge Garcia — academic website

Source files for the personal academic website of Serge Garcia.

## Main pages

- `index.qmd` — home
- `research.qmd` — research agenda and methods
- `projects.qmd` — projects, scientific leadership and policy impact
- `publications.qmd` — selected publications
- `teaching.qmd` — teaching and PhD supervision
- `cv.qmd` — short CV
- `assets/Serge-Garcia-CV-2026.pdf` — downloadable full CV

## Deployment

The site is built with Quarto and automatically deployed to GitHub Pages by `.github/workflows/publish.yml` after each commit to the `main` branch.

## Editing

Most updates only require editing one `.qmd` file in GitHub. Committing the change automatically rebuilds the public site.
